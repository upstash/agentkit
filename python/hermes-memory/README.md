# upstash-hermes-memory

An Upstash Redis memory provider for [Hermes Agent](https://hermes-agent.nousresearch.com), built on
the same Redis Search layout as `@upstash/agentkit-sdk`'s `AgentMemory` and `ChatHistory`.

**Status: scaffold.** The package is at `0.0.0`, which `scripts/publish-python.mjs` treats as
unreleased, so nothing is published to PyPI yet. The provider itself is tracked in DX-3182.
